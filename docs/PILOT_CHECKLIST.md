# Pilot checklist

Two weeks with the marketing team plus Sales as the first requesting department. Report problems in the pilot WhatsApp group with a screenshot, the page, and what you expected; Adham triages daily.

## Before day 1 (Adham)

- [ ] Production deployed (`docs/DEPLOYMENT.md`), first admin created, temporary password changed
- [ ] Pilot branch: exact coordinates and radius (stand at the branch, "Use my current location"), public IPs for the Wi-Fi fallback, check-in methods, desks
- [ ] Accounts created for the pilot users with the right roles and teams; temporary passwords handed over privately
- [ ] HR set this year's leave allowances and holidays
- [ ] Sales' default approver set (`/admin/organisation`)
- [ ] Settings reviewed: stage targets, WIP limit, monthly post target, lateness grace
- [ ] `/admin/launch` shows nothing left to fix
- [ ] Monthly gates, gate owners and fixed meeting times reviewed

## What everyone should try in week 1

- [ ] Sign in, change the temporary password, create your character
- [ ] Check in by location at the branch (allow location when the phone asks); check out; try a field day with a place name; try the Wi-Fi fallback once
- [ ] Set your status (focus, meeting, shoot, break) and watch it change on a teammate's map
- [ ] Find your cards in My work; comment with an @mention; attach a file
- [ ] Request a leave day and a work-from-home day; approvers approve from Approvals
- [ ] Switch to Arabic and back; use the app on your phone (add it to the home screen)
- [ ] Start from My Day; book a meeting, turn an action into a card; update your Team week; send kudos; tap to walk on the map; turn on phone notifications

## Role-specific

- **Traffic:** accept, return with missing items, brief and start production; check the workload view and stage timers
- **Performance lead:** add visual suggestions or "No input" on new requests
- **Creative lead:** approve or request changes (with a reason) from the inbox, with media previews
- **Sales (requesters):** submit next month's strategic plan and one urgent request; follow statuses; confirm a deliverable; resubmit a returned request
- **Community:** schedule ready cards on the content calendar, reschedule by drag, preview the feed, mark posts as published
- **HR:** export attendance and leaves for a date range; edit an allowance
- **Leadership:** read the workflow and attendance dashboards

## End of week 2

- [ ] Five-minute survey: what saved time, what got in the way, what's missing
- [ ] Review the dashboards with leadership
- [ ] Decide the backlog for weeks 2 to 4 (`docs/BUILD_PLAN.md`)
